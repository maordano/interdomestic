Taxonomía de Relaciones Humanas y Dispositivos de Interacción

Infraestructura de Artefacto y Constitución del Grupo Responsable o ‘Core Team’ (Fase de Preparación)

Autor/a

M. A. Ordano

Fecha de publicación

29 de julio de 2026

Fecha de última modificación

30 de julio de 2026

1. Declaración de Principios (FAIR / CARE)

Este proyecto adopta de manera nativa los principios FAIR (Findable, Accessible, Interoperable, Reusable) para la gestión de datos e infraestructuras, en simetría con los principios CARE (Collective Benefit, Authority to Control, Responsibility, Ethics) para la gestión de datos humanos, grupales y comunitarios.

  • FAIR: Infraestructura abierta, metadatos legibles por máquina y persistencia de artefactos.
  • CARE: Retribución comunitaria, control de la interacción, responsabilidad en el sesgo de dispositivos y diseño ético.

2. Taxonomía de Árbol: Humanos y Dispositivos

La infraestructura del artefacto se entiende como una red entre personas y funciones humanas (roles, contribuciones al proyecto) y los dispositivos inorgánicos y agentes no-humanos (dispositivos de interacción, sensores, interfaces).

Atendiendo a la complejidad ecosistémica del proyecto, la taxonomía contempla la inclusión potencial de especies de la vida silvestre (como plantas o animales domesticados), reconociendo su rol como entidades con agencia dentro del entorno de interacción, interactuando con los dispositivos en el conjunto del equipo técnico.

3. Modelo de Contribución (Contributorship Matrix)

Inspirado en la lógica de clasificación de contribuciones y autoría, definimos los roles del Core Team por el tipo de interacción con el artefacto y el grupo o comunidad (no necesariamente por jerarquía).

Rol / Agente Responsabilidad Principal Principio Tipo de Interacción con el Dispositivo
Responsable FAIR Curaduría de datos, metadatos y apertura. FAIR (Interoperable) Gestión de APIs y Repositorios.
Responsable CARE Consentimiento local, soberanía de datos. CARE (Ética) Auditoría de interfaces y privacidad.
Diseño de Artefacto Desarrollo de hardware/software base. FAIR (Reusable) Programación de firmware y firmware OTA.

4. Explorador Interactivo de Relaciones

Este módulo permite registrar agentes (humanos y dispositivos), visualizarlos como un grafo de nodos etiquetados (cada nodo muestra su nombre, no hace falta pasar el mouse para identificarlo), y declarar relaciones puntuales entre dos agentes seleccionados con clic.

Cada relación puede exportarse luego a .csv. Los controles y el gráfico viven en un mismo panel para no perder de vista qué elemento se fue cargando.

Cómo usarlo paso a paso: 1) Registra una persona o agente con el formulario. 2) Haz clic en dos nodos del gráfico (primero el origen, después el destino; el nodo elegido se pinta de rojo). 3) Elige el tipo de relación y confirma. 4) Descarga el .csv de formación de grupo.

layoutGrafo = {
  const {width, height} = dimGrafo;
  const colHumano = width * 0.26;
  const colDispositivo = width * 0.74;

  const catsHumano = Object.keys(categoriasHumanas);
  const catsDispositivo = Object.keys(categoriasDispositivos);

  const yCategoria = (tipo, categoria) => {
    const cats = tipo === "Humano" ? catsHumano : catsDispositivo;
    const idx = Math.max(cats.indexOf(categoria), 0);
    const paso = cats.length > 1 ? (0.6 / (cats.length - 1)) : 0;
    return height * (0.22 + idx * paso);
  };

  const contadorCat = new Map();

  const nodes = participantes.map(p => {
    const key = `${p.tipo}::${p.categoria}`;
    const n = contadorCat.get(key) ?? 0;
    contadorCat.set(key, n + 1);
    const cx0 = p.tipo === "Humano" ? colHumano : colDispositivo;
    const cy0 = yCategoria(p.tipo, p.categoria);
    return {
      id: p.id,
      nombre: p.nombre,
      tipo: p.tipo,
      categoria: p.categoria,
      rol: p.rol,
      x: cx0 + (n % 3) * 34 - 34,
      y: cy0 + Math.floor(n / 3) * 34
    };
  });

  const idsValidos = new Set(nodes.map(n => n.id));
  const links = relaciones
    .filter(r => idsValidos.has(r.origen) && idsValidos.has(r.destino))
    .map(r => ({source: r.origen, target: r.destino}));

  const sim = d3.forceSimulation(nodes)
    .force("link", d3.forceLink(links).id(d => d.id).distance(110).strength(0.2))
    .force("charge", d3.forceManyBody().strength(-320))
    .force("collide", d3.forceCollide(38))
    .force("x", d3.forceX(d => d.tipo === "Humano" ? colHumano : colDispositivo).strength(0.12))
    .force("y", d3.forceY(d => yCategoria(d.tipo, d.categoria)).strength(0.18))
    .stop();

  for (let i = 0; i < 300; i++) sim.tick();

  const mapa = new Map();
  nodes.forEach(n => mapa.set(n.id, n));
  return mapa;
}

chart = {
  const {width, height} = dimGrafo;
  const svg = d3.create("svg")
    .attr("viewBox", [0, 0, width, height])
    .attr("width", "100%")
    .attr("height", "auto")
    .style("max-width", "100%")
    .style("font", "14px sans-serif");

  svg.append("text")
    .attr("x", width * 0.26).attr("y", 26)
    .attr("text-anchor", "middle")
    .attr("fill", "#3a7ca5")
    .attr("font-size", "17px")
    .attr("font-weight", "bold")
    .text("Humanos");

  svg.append("text")
    .attr("x", width * 0.74).attr("y", 26)
    .attr("text-anchor", "middle")
    .attr("fill", "#c96f36")
    .attr("font-size", "17px")
    .attr("font-weight", "bold")
    .text("Dispositivos");

  relaciones.forEach(r => {
    const po = layoutGrafo.get(r.origen);
    const pd = layoutGrafo.get(r.destino);
    if (!po || !pd) return;
    svg.append("line")
      .attr("x1", po.x).attr("y1", po.y)
      .attr("x2", pd.x).attr("y2", pd.y)
      .attr("stroke", "#8892a0")
      .attr("stroke-width", 2)
      .attr("stroke-opacity", 0.65);
  });

  const seleccionActual = new Set([seleccionOrigen, seleccionDestino].filter(x => x));
  const nodos = Array.from(layoutGrafo.values());

  const grupo = svg.selectAll("g.nodo")
    .data(nodos, d => d.id)
    .join("g")
    .attr("class", "nodo")
    .attr("transform", d => `translate(${d.x},${d.y})`)
    .style("cursor", "pointer");

  grupo.append("circle")
    .attr("class", "punto")
    .attr("r", d => seleccionActual.has(d.id) ? 17 : 13)
    .attr("fill", d => seleccionActual.has(d.id) ? "#e63946" : (d.tipo === "Humano" ? "#3a7ca5" : "#c96f36"))
    .attr("stroke", "#ffffff")
    .attr("stroke-width", 2);

  grupo.append("text")
    .attr("x", 18)
    .attr("y", 5)
    .attr("font-size", "14px")
    .attr("fill", "#2c2c2c")
    .text(d => d.nombre);

  grupo.append("title")
    .text(d => `${d.nombre} — ${d.categoria} / ${d.rol}`);

  grupo
    .on("mouseover", function() {
      d3.select(this).select("circle.punto").attr("stroke", "#2c3e50").attr("stroke-width", 3.5);
    })
    .on("mouseout", function(event, d) {
      d3.select(this).select("circle.punto").attr("stroke", "#ffffff").attr("stroke-width", 2);
    })
    .on("click", function(event, d) {
      const id = d.id;
      if (seleccionOrigen === null) {
        mutable seleccionOrigen = id;
      } else if (seleccionDestino === null && id !== seleccionOrigen) {
        mutable seleccionDestino = id;
      } else {
        mutable seleccionOrigen = id;
        mutable seleccionDestino = null;
      }
    });

  return svg.node();
}

viewof exportarCSV = Inputs.button("Descargar CSV de relaciones", {
  value: null,
  reduce: () => {
    const escapar = (v) => `"${(v ?? "").toString().replace(/"/g, '""')}"`;
    const encabezado = ["origen_id", "origen_nombre", "origen_tipo", "origen_categoria", "origen_rol",
                         "tipo_relacion",
                         "destino_id", "destino_nombre", "destino_tipo", "destino_categoria", "destino_rol"].join(",");

    const filas = relaciones.map(r => {
      const o = participantes.find(p => p.id === r.origen) ?? {};
      const d = participantes.find(p => p.id === r.destino) ?? {};
      return [o.id, o.nombre, o.tipo, o.categoria, o.rol,
              r.tipo,
              d.id, d.nombre, d.tipo, d.categoria, d.rol].map(escapar).join(",");
    });

    const csv = [encabezado, ...filas].join("\n");
    const blob = new Blob([csv], {type: "text/csv;charset=utf-8;"});
    const url = URL.createObjectURL(blob);
    const a = document.createElement("a");
    a.href = url;
    a.download = "relaciones_taxonomia_interdomestic.csv";
    document.body.appendChild(a);
    a.click();
    setTimeout(() => {
      document.body.removeChild(a);
      URL.revokeObjectURL(url);
    }, 100);

    return null;
  }
})

Código 
fichasParticipantes = {
  const eliminarParticipante = (id) => {
    mutable participantes = participantes.filter(p => p.id !== id);
    mutable relaciones = relaciones.filter(r => r.origen !== id && r.destino !== id);
  };

  if (participantes.length === 0) {
    return html`<p><em>Todavía no se registraron agentes.</em></p>`;
  }

  const tarjetas = participantes.map(p => html`<div class="card-participante">
    <span class="rel-badge">${p.tipo}</span>
    <span class="rel-badge">${p.categoria}</span>
    <strong>${p.nombre}</strong> — ${p.rol}
    <div style="margin-top:6px;"><button onclick=${() => eliminarParticipante(p.id)}>Eliminar agente</button></div>
  </div>`);

  return html`<div>${tarjetas}</div>`;
}

tablaRelaciones = {
  const eliminarRelacion = (id) => {
    mutable relaciones = relaciones.filter(r => r.id !== id);
  };

  if (relaciones.length === 0) {
    return html`<p><em>Todavía no se registraron relaciones. Seleccioná dos nodos en el gráfico.</em></p>`;
  }

  const filas = relaciones.map(r => {
    const o = participantes.find(p => p.id === r.origen);
    const d = participantes.find(p => p.id === r.destino);
    return html`<tr>
      <td>${o ? o.nombre : "(eliminado)"}</td>
      <td>${o ? o.tipo : ""}</td>
      <td>${r.tipo}</td>
      <td>${d ? d.nombre : "(eliminado)"}</td>
      <td>${d ? d.tipo : ""}</td>
      <td><button onclick=${() => eliminarRelacion(r.id)}>Eliminar</button></td>
    </tr>`;
  });

  return html`<table class="tabla-relaciones">
    <thead><tr><th>Origen</th><th>Tipo origen</th><th>Relación</th><th>Destino</th><th>Tipo destino</th><th></th></tr></thead>
    <tbody>${filas}</tbody>
  </table>`;
}

5. Integración en el Plan de Gestión de Datos (PGD)

Esta taxonomía opera en la Fase de Preparación del ciclo de vida del proyecto de investigación. Asegura que:

  1. Cada dispositivo tenga una persona humana responsable asignada.
  2. Cada flujo de datos respete la procedencia e integridad (FAIR).
  3. Los grupos o comunidades impactadas por los dispositivos “mantengan soberanía” sobre los datos capturados (CARE).
